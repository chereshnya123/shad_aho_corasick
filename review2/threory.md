# Описание решения

## Ограничения на ответ
По условии задачи, переезд осуществляют $N$ людей. У каждого человека из условий задачи есть слитки золота. Обозначим их количество как $g_i$

Наш ответ не может быть больше $max(g_i)$, так как это значение достижимо, если вообще не проводить перераспределение слитков. В то же время, наш ответ не может быть меньше чем $\frac{\sum_{i}{g_i}}{N}$, так как надо перевезти все имеющиеся слитки.

Таким образом, наш ответ находится в интервале $[\frac{\sum_{i}{g_i}}{N}; max(g_i)]$. Будем искать его бинарным поиском. Опишем метод ниже

## Построение графа
Для решения задачи построим ориентированный граф $G = (V, E)$ из $N + 2$ вершин: 
$$V = \{v_1, \dots v_n, s, t\}, \text{ где }s - \text{ источник}, \ t - \text{сток}$$

Рёбрами в нашем графе будут все рёбра, поданные на вход программы. Дополнительно проведём рёбра из источника $s$ во все вершины $v_1, \dots, v_n$ и из стока $t$ во все вершины $v_1, \dots, v_n$.

Назначим ребрам назначим *пропускную способность*: 

$$\forall v_iv_j \in E \text{\ \ }c(v_iv_j) = \infty$$
$$\forall sv_i \in E \text{\ \ }c(sv_i) = g_i$$

Также для любого ребра $vu$ проведём ребро $uv$ и назначим ему **нулевую** пропускную способность.

## Бинарный поиск ответа

Методом бинарного поиска будет перебирать число $x \in [\frac{\sum_{i}{g_i}}{N}; max(g_i)]$. Далее будем проверять, можно ли перераспределить золотые слитки так, чтобы у наиболее загруженного человека было не более чем $x$ слитков. Значит, ответ $\text{ans} \le x$ и мы должны сдвинуть правую границу на $x$ и продолжить поиск.

Иначе сдвинуть левую границу на $x+1$. Так как если невозможно распределение, в котором самый загруженный человек несёт не более $x$, то это значит, что самый загруженный человек обязан нести строго больше $x$. Значит, проверять значения меньше $x$ не имеет смысла.

## Проверка ответа

Для проверки того, что существует такое распределение, что максимально загруженный человек несёт не больше X мы сделаем следующее:
1. $\forall vt \in E$ присвоим $c(vt) = x$
2. Построим максимальный поток в получившемся графе любым известным методом. Например, Preflow Push

Если максимальный поток имеет избыток в стоке равный сумме слитков, то это значит следующее:
1. Каждая вершина имеет избыток не больший $x$
2. Сумма слитков золота, готовых к переезду (избыток в стоке) равна общему числу слитков золота
3. Искомое распределение задаётся функцией потока. $f(v_iv_j) = g$ значит, что человек $v_i$ должен передать $v_j$ ровно $g$ слитков золота.

## Сложность

Для предложенного решения нам придется хранить граф, количество золота для каждого, а также необходимые данные для `Preflow Push`. Это $O(V + E)$
Сложность алгоритма `Preflow Push` по времени - $O(V^2E)$. Этот алгоритм запускается для каждого шага бинпоиска. Шагов всего - $O(log(max(g_i)))$. Таким образом, общая сложность по времени -  $O(V^2E * log(max(g_i)))$
